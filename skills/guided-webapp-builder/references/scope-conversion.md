# Convert Large Ideas Into A Teachable Prototype

Use the business workflow while replacing risky or time-consuming infrastructure.

| Original request | First-session prototype |
|---|---|
| Connect to a live CRM | Upload an anonymized sample CSV or enter sample rows manually |
| Analyze real customers | Use synthetic records with the same column names |
| Send messages automatically | Generate a reviewable, copyable draft |
| Publish to an external platform | Prepare title, body, image brief, and a manual publishing checklist |
| Add login and roles | Show one fixed role and defer identity management |
| Use a production database | Use in-memory state or localStorage with a reset button |
| Build an AI API feature | Demonstrate with deterministic sample rules or prepared output |
| Make a native mobile app | Build a responsive web page that opens from a URL |
| Build several dashboards | Keep one decision screen and one core metric |
| Predict revenue perfectly | Show assumptions, a scenario range, and a human review step |

## Scope Test

The first checkpoint is teachable only when the learner can answer:

1. Who uses it?
2. What do they enter?
3. What single rule runs?
4. What appears when it succeeds?
5. What must a person review?
6. What is explicitly deferred?

If more than one answer is still broad, reduce the task before editing code.
